전파도 빛도 못 쓰는 방에서 소리로 데이터를 넘길 수 있습니다. 막는 것은 잔향이 아니라 스피커와 마이크를 어디에 두느냐입니다. 아래 화면은 M-FSK 변조·감지 알고리즘을 실제와 같은 원리로 브라우저에서 시뮬레이션해, 잔향 시간이 아니라 직접음 대 잔향 에너지비(DRR)가 링크 성립을 가른다는 것을 보여줍니다.

빠른 시나리오

스피커·마이크를 어디에 두느냐로 배치를 바꿔봅니다. 값은 DRR을 중심으로 방·거리·소음까지 함께 바뀝니다.

잔향 시간 T60

0.5초

직접음 대 잔향비 DRR 핵심 변수

+12dB

심볼 사이 무음 구간입니다. 길수록 잔향 꼬리가 가라앉을 시간을 주지만 처리량은 줄어듭니다.

실측: 우리가 실제로 돌려본 결과 실측

위 슬라이더는 브라우저 시뮬레이션입니다. 아래는 그와 별개로 저희가 실제 실험에서 측정한 값입니다.

  • 320셀 스윕에서 SNR 0dB, 스피커 롤오프, 코덱 컷오프는 전부 통과했습니다. 링크를 끊는 축은 잔향 하나였습니다.
  • 잔향을 직접음 대 잔향비로 다시 모델링하니 결론이 바뀌었습니다. DRR +12dB와 +6dB에서는 T60 0.8초까지 링크가 성립하고, DRR 0dB와 -6dB에서는 성립하지 않습니다.
  • 가드 인터벌 가설은 반증됐습니다. 고친 잔향 모델로 다시 잰 384셀에서도 0 / 12 / 24 / 48ms가 근초음파 캐리어의 통과 셀 수를 24/48로 똑같이 두었고 처리량만 166.7bps에서 55.6bps로 떨어뜨렸습니다. 유일한 예외는 가청 캐리어에 48ms를 걸었을 때 직접음 대 잔향비 0dB에서 3셀을 회복한 것입니다.
  • 근초음파 15kHz 16-FSK 기준 166.7bps입니다.
  • 손실 구간을 견디는 분수부호를 얹으면 25% 손실까지 2.0배 오버헤드로 96.9% 복원됩니다.

정직하게 말하면

이 데모는 브라우저에서 시뮬레이션을 돌립니다. 실제 스피커와 마이크로 공기 중을 건넌 측정이 아닙니다. 응답성을 위해 실제 오디오 표본화율(44.1kHz)보다 훨씬 낮은 내부 표본화율로 계산하고, 톤 주파수도 근초음파 대역을 대표하도록 낮춰 스케일한 값을 씁니다. 변조·정합 필터·오류율 계산 로직 자체는 실제와 같은 원리(M-FSK 변조, Goertzel 에너지 판정)로 동작합니다. 다만 표본화율을 낮춘 탓에 잔향 꼬리가 실제보다 거칠어서, 경계 근처(직접음 대 잔향비 +6dB, 잔향 0.8초)에서는 이 화면이 가드 0ms를 불성립으로 보여 줍니다. 같은 셀을 클러스터에서 더 촘촘한 조건으로 재면 가드 0ms도 성립합니다. 위 실측 항목의 가드 무효 결론은 후자 기준이며, 두 값이 갈리는 이 경계를 감추지 않고 적어 둡니다.

잔향 모델은 지수 감쇠 잡음 꼬리에 직접음을 얹은 합성 임펄스 응답입니다. 실제 방의 초기 반사 구조는 벽·가구·각도에 따라 이보다 훨씬 복잡합니다. 근초음파 데이터 링크는 문헌 기준 10~230bps 수준이고 상당수가 은닉 채널(공격 기법) 연구입니다. 저희는 이 방식을 빠른 통신 수단이라고도, 보안 제품이라고도 말하지 않습니다. 전파와 빛이 막힌 자리에서 적은 양의 데이터를 단방향으로 넘기는 용도입니다.

실제 도입 시에는 그 방에서 DRR을 직접 재야 합니다. 이 데모의 DRR은 사용자가 고르는 값이지, 특정 스피커·마이크·방을 측정해 나온 값이 아닙니다.
