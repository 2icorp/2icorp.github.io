대화형 에이전트 오케스트레이션

"부산 출장 준비해줘" 한마디로, 앱 열 개를 대신 연다

공공·생활 서비스 · 소상공인 약 5주 (측정 1 + 실증 4) 정부 바우처 적합
문제의 대가 · 도구 전환수십 개 앱·사이트 왕복

문제의 대가

한 가지 일을 끝내려 예매·날씨·일정·쇼핑·행정 서류를 각각 다른 앱과 사이트에서 처리합니다. 여정 하나에 화면 열 개를 오가고, 타이핑이 힘든 사람에겐 진입 자체가 벽입니다.

통찰

필요한 건 더 많은 앱이 아니라, 한 문장의 의도를 이해해 여러 도구를 대신 엮어 실행하고 하나의 답으로 합쳐주는 오케스트레이터입니다. '택배 어디야' 같은 단발 질의와 '부산 출장 준비해줘' 같은 여정 단위 요청의 차이가 핵심입니다.

2i의 방식

자연어 의도를 분해해 필요한 도구를 순차·병렬로 호출하고 결과를 하나로 병합합니다. 개인화 메모리로 반복 입력을 없애고, 도구는 표준 어댑터로 붙여 확장합니다. 말로 묻고 말로 답받는 음성 우선 흐름이라 손이 자유롭지 않은 순간에도 씁니다.

게이지 방식으로 진행합니다 · 측정 → 실증 → 이관

측정 게이트

자주 하는 여정별로 지금 몇 개 도구를 몇 분에 걸쳐 오가는지, 도구 전환 마찰을 측정합니다.

실증 게이트

핵심 여정 3종을 오프라인 오케스트레이터로 자동화해 의도 분류 정확도와 멀티스텝 체인 성공률을 확인합니다.

이관 게이트

검증된 파이프라인을 실제 도구 어댑터와 개인화 메모리에 연동해 여정을 한 문장으로 처리합니다.

사용 기술

Python 표준 라이브러리 기반: 자연어 의도 → 분류·슬롯 추출 → 도구 DAG 순차·병렬 실행(목 어댑터: 날씨·기차예매·캘린더·쇼핑비교·문서) → 결과 병합 + 음성 요약 스크립트. 규칙 라우터(LLM 선택·오프라인 폴백) + 개인화 메모리. 완전 오프라인·합성 데이터·유료 API 0.

그래서 무엇이 열리나

도구를 고를 필요 없이 '해줘' 한마디로 여정이 끝나고, 타이핑이 힘든 사람도 말로 접근합니다. 흩어진 도구가 하나의 대화 창구로 모입니다.

정부 바우처 활용

대화형 업무 자동화·민원/고객 응대 원스톱 도입 목적이라 공공·소상공인 디지털 전환 지원사업, AX 바우처와 연계에 적합. 지원 규모·요건은 연도별 공고에 따르며, 복잡한 신청·행정은 2i가 함께 처리합니다.

왜 2i인가

대형 SI가 안 건드리는 중소·중견의 소규모·비정형 과제를, 진단부터 이관까지 한 사람이 책임지고 봅니다. 화려한 제안서 대신 측정된 진단과 검증된 PoC로 신뢰를 먼저 만듭니다.

자주 묻는 질문

Q. 데이터가 정리돼 있지 않아도 되나요?

네. 측정 게이트가 바로 흩어진 데이터와 현장을 정리해 무엇부터 할지 정하는 단계입니다. 준비가 안 됐다는 것 자체가 출발점입니다.

Q. 기간과 비용은 어느 정도인가요?

이 사례 기준 약 5주 (측정 1 + 실증 4) 정도이며, 범위와 데이터 상태에 따라 조정됩니다. 상당 부분을 정부 AX 바우처로 충당해 실부담을 크게 낮출 수 있습니다.

Q. 하다가 안 되면 어떻게 되나요?

그래서 실증 게이트가 있습니다. 큰돈을 걸기 전에 될지 안 될지를 작은 실증으로 먼저 확인하고, 목표 델타에 못 미치면 확장하지 않습니다.

Q. 사람 일자리를 없애는 건가요?

아닙니다. 사람을 대체하는 게 아니라, 반복 업무를 걷어내 사람이 판단과 관계에 집중하도록 속도와 정확도를 보완하는 방식입니다.
