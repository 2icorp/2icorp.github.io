## 무엇을 재는가

무선 신호처리에서 딥러닝이 결국 고전 방법을 다 이긴다는 통념이 있습니다. 이
통념을 검증 가능한 여섯 개 질문으로 좁혀서 실측했습니다. 변조분류, 고정
오탐률 간섭탐지, 드론 무선신호 오픈셋 거부, 채널추정, 무선 지문(RF
fingerprint) 융합, 동일 채널 신호분리입니다. 모든 비교는 같은 데이터·같은
학습/테스트 분할·같은 평가지표 위에서 했고, 어느 쪽에도 유리한 전처리를
주지 않았습니다.

## 결과 — 승자는 과제마다 갈렸습니다

표준 공개 데이터셋 **RadioML2016.10a**(6dB SNR)에서 변조분류는 고전 방법
(28차원 물리 특징 + LightGBM, 정확도 0.855)이 딥러닝(트랜스포머, 0.681)을
뚜렷하게 이겼습니다. 학습 데이터를 539개에서 2,000개로 늘려도 이 우위는
유지됐고, 고전 곡선을 9,900개까지 더 늘려 봐도 완만히 정체하는 양상이었습니다
(같은 지점의 딥러닝 재측정은 완료하지 못해 교차점 존재 여부는 확인하지
못했습니다). 고정 오탐률을 요구하는 간섭탐지에서는 고전 CFAR 계열 탐지기가
잡음 바닥이 12dB 흔들리는 조건에서도 목표 오탐률을 그대로 지켰지만, 제약
없는 이진 딥러닝 탐지기는 같은 조건에서 오탐률이 1.0으로 폭발했습니다.
공개 데이터셋 **DroneRF**(CC BY 4.0)로 잰 드론 무선신호 오픈셋 거부에서는
단일 관측(K=1) 기준으로 고전 방법의 미지 장치 거부율이 딥러닝 대비 5.7배
높았습니다.

반대로 딥러닝이 뚜렷하게 이긴 과제도 있습니다. 동일 채널에 겹친 두 무선
신호를 분리하는 과제에서 학습형 분리기(Conv-TasNet 변형)는 SI-SDRi
+3.01dB를 기록했지만, 고전 독립성분분석(ICA) 기반 방법은 -14.25dB로
오히려 혼합 신호보다 더 나빴습니다. 무선 지문 융합에서도 딥러닝 임베딩이
자체 고전 융합 기준선을 이겼습니다(AUROC 0.9994 대 0.945, K=50 융합).
다만 이 승리에는 조건이 여러 겹 붙습니다. 단일 패킷(K=1) 기준 외부 문헌
대비로는 오히려 뒤지고, 실제 보안 운영점(오탐률 0.1%에서의 탐지율)에서는
둘 다 약하며, 융합에 쓴 관측이 서로 독립적인지에 대한 방법론적 우려도
사후에 제기됐습니다. 채널추정은 방법론에 결함이 있던 초기 실험 외에 확정된
결과가 없어 정직하게 미검증으로 남겼습니다.

| 과제 | 승자 | 핵심 수치 |
|---|---|---|
| 변조분류 (RadioML2016.10a) | 고전 | 0.855 vs 0.681 |
| 고정 오탐률 간섭탐지 | 고전 | 드리프트 후 오탐률 0.0 vs 1.0 |
| 드론 오픈셋 거부 (K=1) | 고전 | 미지거부율 5.7배 |
| 채널추정/등화 | 미검증 | 방법론 결함 있는 초기결과만 존재 |
| 무선 지문 융합 (K=50) | 딥러닝 (다중 조건) | AUROC 0.9994 vs 0.945 |
| 동일 채널 신호분리 | 딥러닝 | SI-SDRi +3.01dB vs -14.25dB |

## 방법 (요약)

탐지 과제는 임계값을 간섭이 없는 학습 구간 통계에서 목표 오탐률에 맞춰
역산하고, 테스트 구간에 변경 없이 적용하는 CFAR(constant-false-alarm-rate)
규율을 따랐습니다. 채널추정 실험에서는 딥러닝이 "이긴" 사례 일부가 실제로는
더 약한 순진한 기준선(naive LS)과의 비교였다는 방법론 결함을 발견했고, 이후
모든 비교에 고전 성능 사다리(순진한 방법부터 오라클급까지)를 두고 어느
기준선 대비 승리인지를 명시했습니다.

## 정직한 한계

간섭탐지·간섭 위치추정·O-RAN/5G 시나리오는 전부 합성 데이터이며 실제 전파
환경을 반영하지 않습니다. 동일 채널 신호분리는 실제 다중발신원 공개
데이터셋의 라이선스가 불명확해 같은 문제 구조를 자체 합성한 혼합 신호로
실험했습니다. 무선 지문 융합의 핵심 데이터셋(WiSig)은 비상업·연구 목적
한정 라이선스입니다. 드론 오픈셋 비교는 고전과 딥러닝이 서로 다른
데이터셋(DroneRF/CardRF)에서 얻은 결과라 동일 데이터 위의 직접 대조는
아닙니다. 채널추정은 방법론을 고친 재설계가 준비됐지만 이 발행 시점까지
실제 GPU 실행이 완료되지 않았습니다.

## 왜 이게 자랑거리인가

이 벤치마크의 가치는 어느 한쪽을 응원하는 데 있지 않습니다. "딥러닝이
신호처리 전반을 대체한다"는 명제도, "고전이 항상 충분하다"는 반대 명제도
여섯 개 과제의 실측 근거로는 지지되지 않습니다. 승패를 가른 것은 각 과제의
구조였습니다. 학습 데이터가 작고 물리적으로 해석 가능한 특징이 있는
과제는 고전이 유리했고, 표현 학습 자체가 과제인 데이터가 풍부한 과제는
딥러닝이 유리했습니다. PoC 예산을 지키려면, 어느 방법을 팔기 전에 먼저
과제의 구조를 재는 것이 순서라고 저희는 생각합니다.
